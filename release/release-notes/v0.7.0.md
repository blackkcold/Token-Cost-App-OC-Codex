## OpenCode Skills 只读面板 / OpenCode Skills Read-Only Panel 🧩

全新的 **Skills 管理器**现已上线，当前阶段为**纯只读**，帮助用户了解已安装的 OpenCode skills 及其安全权限。

**核心能力**：

- **Global Skill 发现**：自动扫描 `~/.config/opencode/skills/` 目录，发现所有已安装 skill 及其 `SKILL.md` frontmatter 元数据
- **Manifest 校验**：解析并展示 skill 名称、描述、位置等基本信息
- **Permission 权限可视化**：图形化展示每个 skill 的权限规则链（allow/ask/deny），一目了然
- **8-Agent 可用性矩阵**：按 OpenCode 内置 8 个 agent（build/explore/general/librarian/oracle/metis/momus/Sisyphus-Junior）展示各 skill 在各 agent 上的可用性
- **多维度过滤**：支持按来源（builtin/user）、状态（active/inactive）、标签（security/browser/automation 等）快速筛选
- **Section 分组列表**：按首字母分组 + 自定义排序，快速定位
- **Liquid Glass 毛玻璃 UI**：遵循 macOS 设计语言，半透明模糊背景
- **Skill 正文预览**：折叠/展开查看 SKILL.md 完整内容
- **Settings 显示偏好**：设置页新增 Skills 展示偏好配置项

**涉及文件**：
`OpenCodeSkillsPageView.swift`, `OpenCodeSkillManifest.swift`, `OpenCodeSkillDiscovery.swift`, `OpenCodeSkillPermissions.swift`, `OpenCodeSkillsReadOnlyStore.swift`, `OpenCodeSkillsModel.swift`, `AppPreferences.swift`

## 安全性 / Security 🔒

v0.7.0 Skills 面板为**纯只读**设计，不修改任何 OpenCode 文件。所有操作仅限：
- 读取 `~/.config/opencode/skills/` 目录中的 SKILL.md 文件
- 在内存中解析 frontmatter 元数据
- 不执行任何 skill 脚本，不修改权限配置

无安全姿态变更，安全级别与 v0.6.0 一致。
