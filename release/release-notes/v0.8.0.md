# v0.8.0 Release Notes

Token Cost App - OC Codex v0.8.0。核心升级：**OpenCode / Codex 趋势图 UI 统一**，总计页新增 **OpenCode + Codex 双源每日用量热力图**，并增强图表数据排序与回归测试，确保热力图在固定卡片尺寸内自动填充、自动换行。

Token Cost App - OC Codex v0.8.0. Core upgrade: **unified OpenCode / Codex trend chart UI**, plus a new **OpenCode + Codex daily usage heatmap** on the total page. Chart ordering and regression coverage have also been improved so the heatmap fills its fixed card area and wraps cells responsively.

---

## 图表 UI 统一 / Unified Chart UI

- OpenCode 趋势图改用与 Codex 相同的共享趋势图组件
- Codex 与 OpenCode 均支持 7 / 30 日范围切换
- 趋势图统一曲线、渐变面积、hover rule、tooltip 样式
- OpenCode 缓存读 / 写信息保留在 tooltip 中，主曲线聚焦实际 token

- OpenCode now uses the same shared trend chart component as Codex
- Both OpenCode and Codex support 7 / 30-day range switching
- Line style, gradient area, hover rule, and tooltip UI are now consistent
- OpenCode cache read / write details remain available in the tooltip while the main curve focuses on actual tokens

**涉及文件 / Files**:
`TrendChartView.swift`, `CodexPageView.swift`, `DetailView.swift`

---

## 双源热力图 / Dual-Source Heatmap

- 总计页新增过去 52 周每日用量热力图
- 自动合并 OpenCode `dailyTotals` 与 Codex daily trend tokens
- 同日双源数据自动相加，未来日期自动排除
- 卡片大小保持不变，内部 cells 根据可用宽高自动计算列数和尺寸
- cells 按日期升序排列，自动换行后仍保持正确时间顺序

- Added a 52-week daily usage heatmap to the total page
- Merges OpenCode `dailyTotals` with Codex daily trend tokens
- Sums both sources on the same date and excludes future dates
- Keeps the card size unchanged while cells resize and reflow based on available space
- Cells render chronologically even after responsive wrapping

**涉及文件 / Files**:
`TotalView.swift`, `TokenHeatmapGrid.swift`, `TokenHeatmapBuilder.swift`

## 质量与文档 / Quality & Docs

- 新增热力图数据构建测试：双源合并、日期排序、未来日期过滤、7x52 rows 兼容
- 新增 DeepSeek V4 官方 API 定价回归测试，避免后续误改计价口径
- 更新 README、CHANGELOG、SECURITY 和开发文档，补齐 v0.8.0 的模块说明与发版资料

- Added heatmap data tests for source merging, chronological ordering, future-date filtering, and 7x52 row compatibility
- Added DeepSeek V4 official API pricing regression tests to guard against accidental pricing changes
- Updated README, CHANGELOG, SECURITY, and development docs for v0.8.0

## 安全性 / Security

v0.8.0 仅新增本地派生图表和测试覆盖，不新增数据写入面或网络请求。OpenCode / Codex 源数据仍保持只读访问。

v0.8.0 only adds locally derived charts and test coverage. It does not add new data-writing surfaces or network requests. OpenCode / Codex source data remains read-only.
