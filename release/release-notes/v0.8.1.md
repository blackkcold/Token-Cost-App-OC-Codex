# v0.8.1 Release Notes

Token Cost App - OC Codex v0.8.1。核心升级：**多 Provider 余额监控正式成型**，设置页升级为**模块化折叠 + 横向响应式布局**，并补齐 **Dock / MenuBar 桌面行为** 与 App 层回归测试，让日常使用更像一个成熟的 macOS 桌面工具。

Token Cost App - OC Codex v0.8.1. Core upgrades: **multi-provider balance monitoring is now first-class**, the settings panel has been rebuilt with **modular collapsible sections and responsive horizontal layout**, and the app now has more polished **Dock / MenuBar desktop behavior** plus stronger app-level regression coverage.

---

## 余额监控 / Balance Monitoring

- 新增 DeepSeek 余额查询，余额监控现覆盖 OpenCode Go / Codex / OpenCode Zen / DeepSeek
- `BalanceManager` 改为运行时可热更新配置，Provider 开关会直接影响实际 checker 构建
- 主窗口与菜单栏都支持展示多窗口配额和多币种余额条目，而不再只依赖单一百分比条
- OpenCode Go 测试连接、环境变量开关、已保存凭证发现链路已经完全对齐

- Added DeepSeek balance queries, bringing coverage to OpenCode Go / Codex / OpenCode Zen / DeepSeek
- `BalanceManager` now hot-updates from runtime configuration, and provider toggles directly affect checker construction
- Both the main window and the menu bar can render multi-window quota information and multi-currency balance entries
- OpenCode Go test-connection flow, environment-variable gating, and saved-credential discovery are now fully aligned

**涉及文件 / Files**:
`BalanceManager.swift`, `BalanceModels.swift`, `DeepSeekBalanceProvider.swift`, `BalanceOverviewCard.swift`, `MenuBarView.swift`

## 设置页体验 / Settings UX

- 设置页按 `全局偏好 / 计费方案 / 余额监控 / OpenCode / Codex / Skills 面板 / 安全边界` 分组
- 一级模块支持折叠，OpenCode / Codex 长路径列表继续保留二级折叠与分页
- `余额监控`、`Skills 面板`、`OpenCode / Codex 来源` 从纵向堆叠改为横向响应式控制网格
- Workspace ID、Auth Cookie、保存/测试连接/浏览器导入等高频操作在宽窗口下会更紧凑地同区展示

- The settings panel is grouped into `Global preferences / Billing / Balance monitoring / OpenCode / Codex / Skills / Safety boundary`
- Top-level modules are collapsible, while OpenCode / Codex long path lists keep their second-level collapse and pagination
- `Balance monitoring`, `Skills`, and `OpenCode / Codex sources` now use responsive horizontal control grids instead of pure vertical stacking
- Workspace ID, Auth Cookie, save/test/import actions are presented more compactly in wider desktop windows

**涉及文件 / Files**:
`SettingsView.swift`, `Components.swift`, `Localizable.strings`

## 桌面行为与测试 / Desktop Behavior & Tests

- 主窗口关闭后自动隐藏 Dock 图标，但保留 MenuBar 后台运行
- 通过 MenuBar 或设置页重新唤起窗口时，会自动恢复正常的 Dock 激活策略
- 新增 `CodexTokenCostAppTests`，覆盖窗口生命周期和 `AppPreferencesModel` 的余额配置持久化
- 余额监控、环境变量 gating、Keychain 发现和配置 round-trip 的核心回归测试全部补齐

- Closing the main window now hides the Dock icon while preserving MenuBar background operation
- Reopening from the MenuBar or settings restores the regular Dock activation policy automatically
- Added `CodexTokenCostAppTests` for window lifecycle behavior and `AppPreferencesModel` balance-config persistence
- Core regression coverage now includes balance monitoring, environment gating, Keychain discovery, and config round-trips

**涉及文件 / Files**:

## 安全性 / Security

v0.8.1 继续保持本地优先。OpenCode Go 的 auth cookie 仍只进入 macOS Keychain，环境变量凭证默认禁用，只有在设置中显式开启后才参与发现链路；Provider token 读取也收紧为显式 Provider 映射，不再宽松回退到错误字段。

v0.8.1 remains local-first. OpenCode Go auth cookies still live only in macOS Keychain, environment-variable credentials stay disabled by default until explicitly enabled in settings, and provider token lookup has been tightened to explicit provider mappings instead of broad fallback behavior.
