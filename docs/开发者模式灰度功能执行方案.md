## 1. 结论先行（v9 修订）

1. Developer Mode 的 **v1 范围必须收缩**：只做本地、只读、确定性、可解释的功能。
2. **不要把运行时开关写成安全边界本身**。真正的边界来自：文件路径 allowlist、secret redaction、联网白名单、显式同意、平台分发约束。
3. **Optimize v1 收紧为仅元数据分析**：不读取任何文件内容（JSONL 行、SQLite 行、JSON 值），仅分析文件大小/数量/修改时间。
4. **任务分类只能先做 heuristics**。RawRow 只有 13 个聚合字段，最多 6 条规则，不过度承诺语义级分类。
5. **SettingsView 内无现有 onChange handler**：所有 Developer Mode onChange 需全新添加，不存在继承或复制问题。
6. **分发模型已明确：本期保持 ad-hoc Direct 非沙箱分发**。当前无 entitlements、无 sandbox、无 Developer ID notarization，项目通过 GitHub Releases 分发。
7. AI 分析不能直接进 v1 默认能力。先把 findings schema、脱敏规则、接收方、endpoint、用户同意、隐私披露写清楚，再决定是否进入后续 phase。
8. 「仅元数据」承诺必须有自动化 enforcement。在 CI 和 build/release 脚本中新增禁止符号检查。
9. **Optimize v1 不得复用会读取内容的 Skills/config 链路**。
10. **外部只读路径不走 SafeFileStore**。`SafeFileStore` 只负责 runtime root；`~/.codex`、`~/.config/opencode`、`~/.agents` 等路径由 `DeveloperFileAccessPolicy` 负责。
11. **CI 必须增加 `swift test`**：当前 CI 仅执行 `swift build`，测试从未运行。

### 6.3 TOCTOU 竞态防护与 API 收口

**DeveloperFileHandle（原子化元数据访问）**：
```swift
public struct DeveloperFileHandle: ~Copyable {
    private let fd: Int32

    public func attributes() throws -> DeveloperFileAttributes
    public func modificationDate() throws -> Date
    public func fileSize() throws -> Int64
    public static func openIfAllowed(
        root: DeveloperAllowedRoot,
        relativePath: DeveloperRelativePath,
        purpose: DeveloperFileAccessPurpose
    ) throws -> DeveloperFileHandle

    deinit {
        if fd >= 0 { close(fd) }
    }
}
```

- 优先用 `openat(rootFD, component, O_RDONLY | O_NOFOLLOW | O_CLOEXEC)` 从 allowlist root fd **逐组件打开**
- 每个目录组件用 `fstatat` 校验 type/dev/ino
- 拒绝 `/System/Volumes/Data` 等 firmlink 边界路径
- 删除 `fcntl(F_GETPATH)` 回退方案（macOS 上不安全）
- `openat()`/`fstat()`/`fstatat()` 调用均含 EINTR 重试循环
- `deinit` 自动 `close(fd)`，防止 fd 泄漏
- 类型标记 `~Copyable`（非 Sendable），杜绝并发 double-close

**DeveloperMetadataAccess 协议**：
```swift
public protocol DeveloperMetadataAccess: Sendable {
    func attributes(root: DeveloperAllowedRoot, relativePath: DeveloperRelativePath) throws -> DeveloperFileAttributes
    func listDirectory(root: DeveloperAllowedRoot, relativePath: DeveloperRelativePath) throws -> [DeveloperDirectoryEntry]
    func exists(root: DeveloperAllowedRoot, relativePath: DeveloperRelativePath) -> Bool
}
```
