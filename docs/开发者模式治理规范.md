## 1. v1 范围定义

### 1.1 核心原则

Developer Mode v1 只做**本地、只读、确定性、可解释**的功能。任何不符合这四条原则的能力，都需要在独立的 Phase 中重新评估，不能混入 v1 默认能力。

| 原则 | 含义 | 反例 |
|------|------|------|
| 本地 | 不依赖网络，不离机运行 | AI 分析上传数据到云端 |
| 只读 | 不修改任何源数据 | 修改 session JSONL、更新数据库 |
| 确定性 | 相同输入产生相同输出 | 基于本地元数据的规则引擎 |
| 可解释 | 用户能理解为什么 | 机器学习模型黑盒决策 |

### 1.2 数据边界

**不读取文件内容**。仅读文件系统元数据（大小、数量、修改时间）。具体而言：

- 允许：`stat()`、`fstat()`、`fstatat()`、`lstat()` 获取文件属性
- 允许：`openat()` + `O_RDONLY | O_NOFOLLOW` 获取 fd 后仅调 `fstat()`
- 允许：`getattrlist()` 获取元数据
- 禁止：`Data(contentsOf:)`、`String(contentsOf:)`、`FileHandle(forReadingAtPath:)`、`pread()`、`mmap()`、`JSONDecoder`、`JSONSerialization`、`sqlite3_open`
- 禁止：ObjC 桥接 API（`NSData(contentsOf:)`、`NSString(contentsOfFile:)`、`NSDictionary(contentsOf:)` 等）
- 禁止：经由现有内容读取入口间接读取（`SafeFileStore.readCodable`、`TokenDatabaseClient`、`SourceDiscoveryService` 等）

### 1.3 网络边界

**不新增自动或隐式网络调用**。现有余额监控和更新检查不受影响。

| Phase | 联网策略 | 说明 |
|-------|---------|------|
| Phase 0-3 | 禁止新增 | 不新增 URLSession、Process、NSWorkspace.open 等 |
| Phase 4 | 需单独评审 | 必须显式列出 endpoint、发送字段、接收方、目的、保留策略 |

### 1.4 数据修改边界

**不修改源数据**。具体禁止项：

- 不修改 SQLite 数据库（OpenCode、Codex 等）
- 不修改 session JSONL 文件
- 不修改用户原始配置文件（`opencode.json`、`oh-my-openagent.json` 等）
- 不修改 Keychain 或 UserDefaults 凭证
- 不修改 `auth.json` 等凭证文件
- 不调用 `SecureCredentialStore.saveWorkspaceID` / `deleteWorkspaceID`

## 2. 安全边界

### 2.1 文件系统 Allowlist / Blocklist

Developer Mode 的文件访问严格限制在以下范围内。

#### Allowlist（v1）

| 范围 | 读取内容 | 说明 |
|------|---------|------|
| `~/Library/Application Support/com.yanghaoran.CodexTokenCost/config/*.json` | 元数据 | 不读 JSON 值 |
| `~/Library/Application Support/com.yanghaoran.CodexTokenCost/latest/*.json` | 元数据 | 仅数量/大小/修改时间 |
| `~/Library/Application Support/com.yanghaoran.CodexTokenCost/snapshots/**/*.json` | 元数据 | 每 source 快照数、最老时间 |
| `~/.codex/sessions/**/*.jsonl`（最大深度 6） | 仅元数据 | 不读 JSONL 行内容 |
| `~/.codex/archived_sessions/**/*.jsonl`（最大深度 6） | 仅元数据 | 不读 JSONL 行内容 |
| `~/.local/share/opencode/opencode.db` | 存在性、修改时间 | 不打开 SQLite |
| `~/.config/opencode/opencode.json` | 存在性、修改时间 | 不读内容 |
| `~/.config/opencode/skills/**` | 目录/文件元数据 | 不读 SKILL.md |

#### Blocklist（v1）

| 范围 | 拒绝原因 |
|------|---------|
| `~/.codex/auth.json`、`~/.local/share/opencode/auth.json` | 直接凭证文件 |
| `~/.config/opencode-bar/opencode-go.json` | 余额凭证输入 |
| `~/Library/Keychains/**`、`~/.ssh/**`、`~/.gnupg/**` | 高敏凭证区 |
| `~/.codex/logs*.sqlite`、`~/.codex/goals*.sqlite`、`~/.codex/memories*.sqlite` | 高噪声/隐私内容 |
| 浏览器目录（Chrome、Edge、Firefox、Safari 等） | Cookie/History SQLite |
| `~/.aws/`、`~/.docker/config.json`、`~/.kube/`、`~/.netrc`、`~/.gitconfig` | 云凭证 |
| `~/.gemini/`、`~/.anthropic/`、`~/.claude/`（除 skills/） | AI provider 配置 |
| `.env`、`.env.*` 文件 | 环境变量文件 |
| `~/.config/opencode/oh-my-openagent.json` | 可能含 API key |
| `~/.npmrc`、`~/.pypirc`、`~/.cargo/credentials.toml` | 包管理器凭证 |
| `~/.config/gcloud/`、`~/.azure/`、`~/.aliyun/` | 云 CLI 凭证 |
| `~/.terraform.d/credentials.tfrc.json`、`~/.cf/config.json` | 云平台凭证 |
| `~/.config/hub` | GitHub CLI OAuth token |

### 2.3 TOCTOU 竞态防护

Developer Mode 的文件元数据访问必须使用 `DeveloperFileHandle`，通过 fd-based 操作避免 Time-of-Check-Time-of-Use 竞态。

**核心实现要求**：

1. 优先用 `openat(rootFD, component, O_RDONLY | O_NOFOLLOW | O_CLOEXEC)` 从 allowlist root fd 逐组件打开
2. 每个目录组件用 `fstatat` 校验 type/dev/ino
3. 拒绝 `/System/Volumes/Data` 等 firmlink 边界路径
4. 删除 `fcntl(F_GETPATH)` 回退方案（macOS 上不安全）
5. `openat()`/`fstat()`/`fstatat()` 调用均含 `EINTR` 重试循环
6. `deinit` 自动 `close(fd)`，防止 fd 泄漏
7. 类型标记 `~Copyable`，杜绝并发 double-close

**使用协议 `DeveloperMetadataAccess`**：

```swift
public protocol DeveloperMetadataAccess: Sendable {
    func attributes(root: DeveloperAllowedRoot, relativePath: DeveloperRelativePath) throws -> DeveloperFileAttributes
    func listDirectory(root: DeveloperAllowedRoot, relativePath: DeveloperRelativePath) throws -> [DeveloperDirectoryEntry]
    func exists(root: DeveloperAllowedRoot, relativePath: DeveloperRelativePath) -> Bool
}
```

### 2.4 联网边界

| Phase | 策略 |
|-------|------|
| Phase 0-3 | 禁止新增自动或隐式网络调用。现有 UpdateChecker、BalanceManager 不受影响。 |
| Phase 4 | 必须显式列出 endpoint 白名单、发送字段、接收方、目的、保留策略，单独征求用户同意。 |

**Developer Mode 代码中禁止出现**：
- `URLSession` 的任何使用
- `Process` 启动外部进程
- `NSWorkspace.open` 打开 URL
- 调用 `UpdateChecker` 或 `OpenCodeGoDashboardFetcher`

## 3. 分发模型

### 3.1 当前状态

| 项目 | 当前事实 |
|------|---------|
| 构建方式 | `swift build` |
| 代码签名 | `codesign --force --deep --sign -`（ad-hoc） |
| Developer ID | 无 |
| `--options runtime` | 无 |
| `.entitlements` | 无 |
| Notarization | 无 |
| Sandbox | 无 |
| 分发渠道 | GitHub Releases（.zip） |

### 3.2 本期约束

- **保持当前 ad-hoc Direct 非沙箱分发**
- **不新增 `.entitlements`**
- **不承诺 MAS 兼容或 Developer ID notarization**
- Developer Mode 的安全边界不依赖 entitlements，而是来自：
  - 应用内 allowlist/blocklist
  - fd-based metadata access
  - 独立目录 + CI banned-symbol enforcement
  - 运行时无网络/无凭证依赖

### 3.3 若未来需要考虑 MAS

- 沙箱限制将直接影响 Developer Mode 的文件扫描能力（需 sandbox read-only entitlement）
- Developer Mode 不能作为隐藏灰度能力进入 MAS 审核
- 需重新评估允许路径与 MAS 兼容性

## 5. 回滚路径

Developer Mode 提供四层回滚路径，按恢复范围从窄到宽排列：

### 5.1 UI 重置（仅重置开发者模式）

| 属性 | 值 |
|------|-----|
| 入口 | Settings → Safety Section →「仅重置开发者模式」 |
| 恢复范围 | 仅 `AppPreferences.developerMode` 字段恢复为默认值（全 false） |
| 不影响 | 语言、主题、计费方案、凭证、其他偏好 |
| 恢复方式 | 同步 `@Published` 状态并落盘 |

### 5.2 UI 重置（全量）

| 属性 | 值 |
|------|-----|
| 入口 | Settings → Safety Section →「重置全部应用偏好」→ 输入 `RESET` |
| 恢复范围 | 整个 `AppPreferences`（包括 Developer Mode） |
| 不影响 | Keychain/UserDefaults 凭证 |
| 恢复方式 | 同步 `@Published preferences`、`AppLocalization` 和 `config/app-preferences.json` |

### 5.3 手动重置（删除 JSON）

| 属性 | 值 |
|------|-----|
| 操作 | 删除 `config/app-preferences.json` |
| 恢复范围 | AppPreferences 全部 |
| 自动行为 | app 下次启动时自动重建为默认值 |
| 不影响 | Keychain/UserDefaults 凭证 |

### 5.4 备份恢复

| 属性 | 值 |
|------|-----|
| 备份位置 | `config/backups/app-preferences/`（保留最近 10 份） |
| 恢复范围 | AppPreferences 全部 |
| 操作 | 从备份目录选择历史版本覆盖当前 JSON |
| 不影响 | Keychain/UserDefaults 凭证 |
